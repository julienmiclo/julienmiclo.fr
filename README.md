### Convention Git

Format:

```
<type>(<portée facultative>): <description>
<corps facultatif>
```

Type:

``feat`` : Ajout

``fix`` : Correction

``refactor`` : Restructuration

``content`` : Contenu

``docs`` : Documentation

``build`` : Dépendances

``chore`` : Maintenance

Portées: ```home```, ```posts```, ```mdx```, ```ui```, ```layout```, ```footer```, ```legal```, ```data```,
```a11y```...
